## 1. 系统概述

### 1.1 系统简介

蠢驴电竞陪玩派单管理系统是一套专为电竞陪玩工作室设计的综合管理平台。系统覆盖从客户管理、订单创建与分配、陪玩接单执行，到报账审核、收入统计的全业务流程，帮助工作室实现高效、规范的运营管理。

### 1.2 技术架构

```
浏览器 (React) ──HTTP──▶ Nest.js 后端 ──▶ PostgreSQL + Redis
                                  △
陪玩桌面端 (Electron 客户端) ──WebSocket──┘
```

- **前端**：React + Ant Design 组件库，响应式 Web 界面
- **后端**：Nest.js (Node.js)，提供 RESTful API + WebSocket 实时通信
- **数据库**：PostgreSQL 16，使用 Prisma ORM
- **缓存**：Redis 7
- **陪玩客户端**：Go 语言编写的桌面代理程序，通过 WebSocket 与服务器保持长连接

### 1.3 四种用户角色

| 角色 | 标识 | 职能概述 |
|------|------|----------|
| **老板 (OWNER)** | OWNER | 查看盈亏统计、管理客户、管理员工、管理工作室、审核客服/陪玩注册 |
| **管理员 (ADMIN)** | ADMIN | 管理所有订单、管理陪玩、管理客户、审核报账、远程控制陪玩电脑 |
| **客服 (CS)** | CS | 在派单工作台创建订单、查看订单池与陪玩状态、查看历史派单记录 |
| **陪玩 (COMPANION)** | COMPANION | 通过桌面客户端接单/确认/完成订单、切换工作/娱乐模式、提交报账 |

## 2. 快速入门

### 2.1 登录系统

1. 在浏览器中打开系统地址（由管理员提供）
2. 进入登录页面，页面顶部显示「蠢驴电竞陪玩派单管理系统」
3. 输入**用户名**和**密码**
4. 点击「登录」按钮
5. 登录成功后，系统会根据你的角色自动跳转到对应的工作页面

> Electron 陪玩客户端登录页支持「记住账号密码」。该功能使用操作系统级安全存储加密凭据，仅在受信任的服务端页面加载时自动填充；浏览器登录仍保持原有方式。

> 陪玩端要换账号登录时，请在右下角托盘菜单点「退出」，输入管理密码通过后客户端会同时清空登录状态和记住的账号密码；下次双击桌面「陪玩管理」会停留在登录页，可直接输入新陪玩信息。

> 管理端「员工管理 → 陪玩管理 → 陪玩列表」中，点击陪玩的头像或用户名会弹出「员工详情」，可直接查看该陪玩的身份证正反面。

### 2.3 页面布局说明

登录后进入主界面，分为三个区域：

- **左侧导航菜单**：根据角色显示对应的功能菜单，可点击切换功能页面。左侧菜单栏可折叠/展开（点击左上角按钮）。
- **顶部栏**：左侧显示折叠按钮，右侧显示当前登录用户名、角色标签和「退出」按钮。
- **版本信息**：客户端版本 / 前端构建 / 服务器地址统一放在「设置」页底部的「版本信息」卡片里；左侧菜单和头像上不再显示版本号与相机徽标（只有排障时才需要看）。
- **设置中心**：所有系统设置按「钱·分账 / 派单·等级 / 陪玩端·客户端 / 门店·通知」四组排在左侧，顶部搜索框可以直接搜（如「分账」「截图」「提成」），找到就点，右侧只显示当前这一项，不用再横着一排 Tab 数过去。
- **设置项的排版**：每一条设置都是「左边名称（统一 180px 宽）、中间输入框、右边一句说明」，说明文字单独占一列自动换行，不会再把名称挤成两行；13 个设置页都是同一套排版，切页面时输入框不会再左右横跳。
- **内容区**：当前选中功能页面的主要操作区域。

### 2.4 首次设置流程

如果你是第一次使用本系统，请按以下顺序完成初始化：

1. **老板登录**：使用 OWNER 账号登录
2. **创建工作室**：进入「工作室管理」页面，创建至少一个工作室
3. **创建员工**：进入「员工管理」页面，为工作室创建 ADMIN、CS、COMPANION 角色的员工账号
4. **授权员工**：CS 和 COMPANION 角色需要授权后才能登录。进入「客户端授权」页面，找到待审核的用户，点击「审核通过」
5. **为陪玩配置客户端**：COMPANION 登录后需下载并运行 Electron 客户端 桌面客户端

## 3. 角色操作指南：老板 (OWNER)

老板拥有系统的最高权限，主要负责查看经营数据和团队管理。

### 3.1 盈亏统计

> 路径：左侧菜单 → **盈亏统计**

此页面用于查看工作室的盈亏数据，包含收入统计、支出记录和利润图表。

**操作步骤：**

1. 点击「盈亏统计」菜单进入页面
2. 系统会弹出**二次密码输入框**，请输入二次密码（默认：`888888`）
3. 验证通过后，页面展示盈亏汇总数据
4. 可切换日视图/月视图查看不同维度的统计
5. 图表区域直观展示收支趋势

> **安全提示**：二次密码验证有效期为 5 分钟，超时后需重新输入。

### 3.1.1 每日统计（客服派单 / 提成核对）

> 路径：左侧菜单 → **每日统计**

用于核对客服每天的派单量与提成，并追踪客户付款去向。

**主要能力：**
- 顶部汇总：发单总数、总金额、客服认领、未接单、已付/未付、微信/支付宝笔数
- 客服汇总：按客服展示发单数、认领数、金额、各工作室单量、陪玩费已付/未付、微信/支付宝到账
- 订单明细：展示订单号、发单客服、认领客服、工作微信、客户付款去向、收款账号、陪玩费状态与方式

**筛选：** 支持日期范围、订单状态、陪玩费状态、游戏名称筛选，点击「查询」或按回车刷新。

### 3.2 客户管理

> 路径：左侧菜单 → **客户管理**

**查看客户列表：**

表格展示所有客户的以下信息：

| 列名 | 说明 | 宽度 |
|------|------|------|
| 客户编号 / 微信号 | 编号在上、客户微信号用小字排在下面；有存单/预约时在下面追加标签（**钉在表格左侧，拖到哪里都看得见是谁**） | 150 |
| 客户昵称 | 订单里登记的客户昵称 | 120 |
| 来源账号 | 该客户从哪个平台账号来的 | 150 |
| 最近订单 | 最近一单的游戏 / 类型 / 金额 / 单双 / 时长 | 220 |
| 来源/时间 | 客户来源、紧急程度、计费方式标签 | 110 |
| 状态 | 客户状态（新客 / 待开发 / 已转化 ……） | 90 |
| 所用微信 | 成交时用的工作微信 | 100 |
| 陪玩 | 当前分配的陪玩（未分配则显示"未分配"） | 110 |
| 最近跟进 | 最近一条跟进记录摘要 + 日期 | 120 |
| 累计消费 | 该客户的总消费金额 | 120 |
| 备注 | 备注内容（陪玩可直接在格子里填） | 200 |
| 操作 | 归属调整 / 编辑 / 删除（**钉在表格右侧，永远不会被挤出去**） | 280 |

> **列宽是定死的：** 上表宽度来自全局规格 `apps/web/src/constants/datasetColumns.ts`（和订单管理、
> 订单池用的是同一份），列宽不随窗口宽度变化、也不会被长内容挤扁。窗口不够宽时**表格横向滚动，
> 「客户编号」固定在左侧、「操作」列固定在右侧**，拖到最右边看备注时也知道自己在看哪个客户、也不用往右拖表格找按钮；
> 点**整行**也能进详情。表头和正文的字号同样由这份规格统一（正文 13px / 表头 11px），
> 所以同样的数据在订单池、订单管理、客户管理里看到的大小是一致的。

> **微信号为什么没有单独的列？** 它并进了第一列「客户编号 / 微信号」：编号只有 1~3 位，
> 单独一列又占宽又认不出人，现在两个信息叠在同一列（上编号、下微信号），拖到最右边也能看到；搜索框照旧支持按微信号搜。

**新建客户：**

1. 点击「新建客户」按钮
2. 在弹出的表单中填写：
   - **微信号**（必填）
   - **平台**（必选，下拉选择：微信/QQ/电话/其他）
   - **平台账号**（选填）
   - **备注**（选填）
3. 点击「保存」

**编辑客户：**

1. 在表格中找到目标客户，点击「编辑」按钮
2. 修改需要更新的字段
3. 点击「保存」

**删除客户：**

1. 点击「删除」按钮
2. 在确认弹窗中点击「确定」完成删除

### 3.2.1 内容查重 + 违禁词检测

> 路径：左侧菜单 → **客户管理 → 内容查重风控**

发布小红书、抖音等平台内容前，可把标题、正文、标签和历史文案粘贴到页面，点击「开始检测」。

- 系统会标记站外导流、诱导私信、低价营销、极限词、异常互动、语境风险等词，并给出修改建议。
- 系统会对比当前文案与历史文案、同批草稿、系统已录笔记的重复度，标出高重复或部分重复内容。
- 需要更准确判断“换词但意思一样”时，可勾选「启用大模型语义查重」；该功能使用系统里已配置的 DeepSeek 或豆包 API。
- 高危项显示为红色，提醒项显示为橙色；处理后建议再次检测，直到页面提示“未发现高危问题”。

### 3.3 员工管理

> 路径：左侧菜单 → **员工管理**

此页面用于创建和管理系统内的所有员工账号（ADMIN、CS、COMPANION）。

**新建员工：**

1. 点击「新建员工」按钮
2. 填写：
   - **用户名**（必填，唯一）
   - **密码**（必填）
   - **角色**（必选：管理员/客服/陪玩）
   - **所属工作室**（必选）
   - 如角色为「陪玩」，还需填写：
     - **报账编号**：陪玩的唯一结算编号
     - **擅长游戏**：多选，如"英雄联盟"、"王者荣耀"
     - **分成比例**：默认为 0.6（即 60%）
3. 点击「保存」

**编辑/删除员工：** 在表格操作列点击对应按钮即可。

**重置密码：** 在员工详情或编辑弹窗中可重置该员工的登录密码。

### 3.4 工作室管理

> 路径：左侧菜单 → **工作室管理**

管理工作室的创建、编辑和删除。

**新建工作室：**

1. 点击「新建工作室」
2. 输入工作室名称
3. 点击「保存」

每个工作室下可包含多个员工、陪玩和客户，数据按工作室隔离。

### 3.5 客户端授权

> 路径：左侧菜单 → **客户端授权**

客服 (CS) 和陪玩 (COMPANION) 角色注册后需要经过授权才能登录系统。

**操作步骤：**

1. 进入「客户端授权」页面，查看待授权用户列表
2. 表格展示：
   - 用户名
   - 角色
   - 所属工作室
   - 注册时间
   - 审核状态（待审核/已通过）
3. 对于待审核的用户，点击「审核通过」
4. 审批后该用户即可正常登录

> **拒绝授权**：如果拒绝，该用户将无法登录系统。

## 4. 角色操作指南：管理员 (ADMIN)

管理员负责日常运营管理，是系统使用最频繁的角色。

### 4.1 派单管理

> 路径：左侧菜单 → **派单管理**

此页面与客服的「派单工作台」功能类似，可查看所有订单、创建订单、指定陪玩。

**查看全部订单：**

- 表格按创建时间倒序显示所有订单
- 可筛选订单状态
- 包含订单号、客户、游戏、金额、派单方式、陪玩、状态等列
- 「主陪 / 接单工作室」列：主陪名字下面标出他所属的工作室；如果这单是**桥接工作室接的**，会显示紫色标签「桥接·光耀电竞」，鼠标悬停可看到「本单由蠢驴电竞发布，光耀电竞的陪玩接单」。

**创建订单：**

1. 点击「创建订单」
2. 填写订单信息（详见 [5.1 派单工作台](#51-派单工作台)）
3. 点击「创建」

**指派陪玩：** 点击订单的「指定陪玩」，从在线空闲陪玩中选择，确认即可。

**取消订单：** 对于待处理状态 (PENDING) 的订单，可点击「取消」。

### 4.2 陪玩管理

> 路径：左侧菜单 → **陪玩管理**

查看所有陪玩的状态和工作情况。

**表格内容：**

- **陪玩姓名**：关联用户名
- **状态**：在线/空闲/忙碌/离线
- **当前模式**：工作模式/娱乐模式
- **擅长游戏**：标签展示
- **在线时长**：当日累计在线时间
- **接单数**：当日完成订单数

### 4.3 客户管理

> 路径：左侧菜单 → **客户管理**

功能与老板的客户管理相同，额外支持**重新分配陪玩**功能。

**重新分配陪玩：**

1. 在客户列表中找到目标客户
2. 点击操作列的「分配陪玩」
3. 从陪玩列表中选择新的陪玩
4. 确认后，该客户的所有新订单将优先派给新分配的陪玩

### 4.4 报账审核

> 路径：左侧菜单 → **报账审核**

这是管理员最核心的工作之一。陪玩完成订单后提交报账，管理员在此审核。

**三栏标签页：**

页面顶部显示三个统计卡片：待审核数量、已通过数量、已拒绝数量。

下方有三个标签页：

| 标签页 | 说明 |
|--------|------|
| **待审核** | 陪玩刚提交、等待审核的报账记录 |
| **已通过** | 已审核通过的记录 |
| **已拒绝** | 已审核拒绝的记录 |

**表格字段：**

| 列名 | 说明 |
|------|------|
| 陪玩 | 提交报账的陪玩姓名 |
| 订单号 | 关联的订单编号 |
| 金额 | 报账金额（红色加粗显示） |
| 支付方式 | 如微信、支付宝等 |
| 截图 | 支付凭证截图缩略图，点击可放大查看 |
| 支付时间 | 实际支付时间 |
| 提交时间 | 报账提交时间 |
| 状态 | 待审核/已通过/已拒绝 |
| 操作 | 通过/拒绝按钮 |

**审核单条报账：**

1. 在「待审核」标签页中，查看报账详情
2. 点击截图缩略图可查看完整支付凭证
3. 确认无误后点击「通过」
4. 如发现问题（金额不符、截图不清等），点击「拒绝」
**金额协商：** 若报账金额与截图实际到账不符，可点击「改价」输入调整金额与说明发起协商；陪玩端在报账系统看到「协商中」记录后，可接受（按新金额通过）或拒绝（退回待审核、保留原金额）。

**批量操作：**

1. 勾选多条待审核记录前的复选框
2. 页面上方出现蓝色操作栏，显示已选数量
3. 点击「批量通过」或「批量拒绝」
4. 在确认弹窗中点击「确定」

> **提示**：批量操作仅在「待审核」标签页可用。切换标签页会自动清除已选记录。

### 4.5 进程黑名单管理

> 路径：左侧菜单 → **进程黑名单** / **进程白名单** / **杀进程日志**

功能：
- 管理陪玩终端禁止运行的软件（如外挂、竞品平台）
- 添加支持两种方式：从陪玩上报进程多选 / 手动输入
- 白名单优先于黑名单（白名单进程不被关闭）
- 22 个系统内置白名单（微信、浏览器等）

**自动结束黑名单进程（总开关，默认关闭）**

页面顶部有一个开关，决定「名单要不要真的动手」：

| 开关 | 行为 |
|------|------|
| 关闭（默认） | 名单只做记录和展示，客户端**不会**结束任何进程 |
| 打开 | 陪玩处于对应状态时，客户端每 10 秒强制结束名单里的进程（正在玩的游戏会直接掉线） |

打开时会弹二次确认。2026-09-20 出过一次事故——陪玩正在「娱乐中」打三角洲，客户端重连时被系统猜成「空闲」，按空闲名单把游戏踢下线，反复掉线。该问题已修复（「补推」不再下发状态、客户端状态未知时不动手），代码里的默认值仍保持关闭。

**开关是「一拨就生效」的：** 改完由服务端当场重算名单并推给所有陪玩端，不用等客户端重连或下一次状态切换；关掉时下发的是**空名单**，正在杀进程的客户端也会立刻停下，所以出问题可以随时一键止损。（2026-09-20 线上已打开，配合「空闲 → 三角洲行动」这一条规则使用。）

操作：
1. 添加进程 → 选择模式 → 多选/手动输入
2. 需要强制整治时，打开顶部「自动结束黑名单进程」开关
3. 推送黑名单 → 全工作室或指定陪玩
4. 终端收到后按状态执行，杀进程日志可查看历史（自动结束的记为 `AUTO_IDLE`）
5. 想停就关开关：关的一瞬间所有在线陪玩端都会收到空名单，不会继续杀进程

权限：ADMIN / OWNER / CS 均可

## 5. 角色操作指南：客服 (CS)

客服是派单系统的核心操作者，负责创建订单和跟踪订单状态。

### 5.1 派单工作台

> 路径：左侧菜单 → **派单工作台**

派单工作台分为三栏布局：

#### 左栏：陪玩状态

实时显示当前工作室所有陪玩的状态：

| 状态 | 标签颜色 | 说明 |
|------|----------|------|
| 在线 (ONLINE) | 红色 | 陪玩在线但未设置为空闲 |
| 空闲 (IDLE) | 绿色 | 陪玩空闲，可接收订单 |
| 忙碌 (BUSY) | 金色 | 陪玩正在处理订单 |
| 离线 (OFFLINE) | 灰色 | 陪玩未登录客户端 |

列表每 10 秒自动刷新。

#### 中栏：订单池

显示所有待派发的池子订单（POOL 模式、状态为 PENDING）。

每个订单卡片展示：
- 游戏名称
- 订单类型标签（新单/续费/复购/打赏）
- 客户微信号
- 订单金额
- 「指定陪玩」按钮
- 「自己抢单」按钮（客服/管理员/老板可见）

> 订单池也是每 10 秒自动刷新。

> **空的时候只占一行**：没人发单时订单池只显示一行虚线提示，不会用一张大插画把下面的
> 「我发布的订单」挤出屏幕。

> **陪玩端订单池可以收起左侧「人员」**：右上角「隐藏人员 / 显示人员」一键切换，收起后订单池多出 246px 宽度，
> 选择会被记住。要在群里喊人、找客服，点左侧菜单的「群聊」即可。

> **超时订单**：立即打订单超过 10 分钟、预约订单超过 60 分钟仍无人抢时，系统会将其从陪玩订单池隐藏，转入客服/管理端的「订单池流转失败明细」。陪玩端不会再看到这些单，也不能抢；由发单客服在流转失败明细里再次发布或标记处理完成。

> **每条订单的时间**：流转失败明细里每一行末尾都标了「🕒发布时间 · 相对时间」（如 `2026/9/14 20:29 · 5天前`），已过期被退回的还会多一个橙色的「↩退回时间」，方便判断这条单是刚发的还是早已过期，再决定要不要再次入池。

点击「指定陪玩」按钮，弹出陪玩选择窗口：
- 下拉列表仅显示在线或空闲的陪玩
- 可搜索陪玩姓名
- 选择后点击「确认派单」，订单将直接指派给该陪玩

#### 修改已发布的订单

发布到订单池的订单如果录错客户微信、房间码、来源账号、游戏、金额或预约时间，可在订单卡片上点击「修改」。只有订单发布者可以修改自己的订单；店长可修改本工作室订单，老板可修改全部订单。保存后：
- 未抢单时，订单池卡片会立即刷新为新信息。
- 已被陪玩抢走时，陪玩端订单和订单管理也会同步更新。
- 客户微信、来源平台等信息会同步到客户主档，避免订单和客户资料不一致。

#### 客服自己抢单（线索养客）

当客户只留下微信、暂时不玩时，陪玩通常不愿抢这种订单。客服可点击订单卡片上的「自己抢单」：

1. 选择要加客户使用的工作微信。
2. 确认后订单变为「客服认领」状态，并退出陪玩抢单池。
3. 客服把客户加到对应工作微信跟进。
4. 等客户确定要打时，在订单列表点击「放回抢单池」，订单重新进入抢单池并标记为「立即打」。

订单列表会保留「认领客服」和「认领微信」，方便追溯由哪位客服、用哪个工作微信养客。

#### 右栏：快捷统计

实时显示三个关键指标：
- **可接单陪玩**：在线 + 空闲的总人数（绿色）
- **忙碌中**：正在处理订单的人数（金色）
- **待派订单**：订单池待派发的订单数（蓝色）

#### 创建订单

点击右上角「创建订单」按钮，弹出订单表单：

| 字段 | 必填 | 说明 |
|------|------|------|
| 订单类型 | 是 | 下拉选择：新单/续费/复购/打赏 |
| 游戏名称 | 是 | 输入游戏名称，如"英雄联盟" |
| 金额 | 是 | 输入数字，支持两位小数，前缀 ¥ |
| 派单方式 | 是 | **入池**：订单只放进抢单池，陪玩自己在池子里抢，不弹窗<br>**广播**：订单进池的同时，本工作室所有在线空闲陪玩的电脑右下角会弹出抢单窗口；到了「桥接工作室等待」时间后，桥接工作室的在线空闲陪玩也会弹一次<br>**指定**：只把订单弹给指定的那位陪玩 |
| 客户 | 否 | 搜索选择已有客户（按微信号搜索） |
| 时长 | 否 | 预计服务时长（小时），步长 0.5 |

填写完成后点击「创建」按钮，订单即创建成功：
- 选择「入池」的订单出现在中栏的订单池，**不会**弹窗打扰陪玩
- 选择「广播」的订单同样进池，并立刻推送给本工作室所有在线空闲陪玩（右下角弹窗）；到了「桥接工作室等待」时间（当前线上 5 分钟）后，这单会同步弹给桥接工作室的在线空闲陪玩（弹窗标题为「🌉 桥接工作室发单！」），两边看到的是同一条单，桥接方也可以直接点「同意」抢单
- 选择「指定」的订单直接发送给指定陪玩的客户端，其他陪玩不会收到

#### 群聊广播（问陪玩某单接不接）

有些单子需要问一圈「谁接」，但陪玩在打游戏，往往不看群消息。这时可以用群聊广播：

1. 点人员列表里的**工作室群聊**，打开群聊窗口
2. 点右上角红色「📢 广播」按钮
3. 填写要广播的内容（200 字以内，例如「还有一单三角洲机密单谁接？接的群里回 1」），点发送

发送后会有两件事同时发生：

- 内容**照常出现在群聊里**，用红底「📢 群聊广播」样式单独标记，方便回头翻聊天记录
- 本工作室**所有在线陪玩的电脑右下角立刻弹出红色提醒窗**，置顶 5 秒后自动消失，不抢他们的键盘鼠标焦点，在打游戏或最小化了客户端时也能看到

## 6. 角色操作指南：陪玩 (COMPANION)

陪玩不需要通过 Web 浏览器工作，而是使用专用的 Electron 客户端 桌面客户端。

### 6.1 安装与启动 Electron 客户端

1. 从管理员处获取 Electron 客户端 可执行文件
2. 配置环境变量：
   - `AGENT_SERVER_URL`：后端服务器地址（默认云服务器 `http://1.117.229.36:3001`；客户端会把历史遗留的 `localhost` / 旧内网地址自动归位到云服务器，避免白屏）
   - `AGENT_TOKEN`：你的登录 Token
3. 运行 Agent 程序
4. 启动后 Agent 自动连接服务器，保持 WebSocket 长连接

### 6.2 本地 Web 界面

Agent 启动后，在浏览器中打开 `http://localhost:9876` 可以看到本地控制面板：

**状态显示：**
- 当前模式（工作/娱乐）
- 工作时间计时
- 娱乐时间计时
- 总在线时长

**模式切换：**

- **工作模式 (WORK)**：切换后状态变为「在线 (ONLINE)」，可以接单
- **娱乐模式 (ENTERTAINMENT)**：切换后状态变为「空闲 (IDLE)」，暂时不接单

**状态不用自己记着切（系统自动跟单走）：** 陪玩登录后就是「空闲」；点「开始首单 / 续单 / 复购」、
或者接到单开始服务，会自动进入「接单中」；点「结束」（结束服务 / 完成订单）后**立刻**回到「空闲」，
不用再手动点一次切换按钮（同时挂两单时，两单都结束才回空闲；副陪也一样）。想休息打游戏时，
自己去点「娱乐」，状态变成「娱乐中」，这时不会被派新单。

模式切换通过点击按钮完成，Agent 会立即同步状态到服务器。

### 6.3 订单通知与处理

当有新订单指派给你时，Agent 会通过 WebSocket 实时接收通知，本地界面会显示订单信息。

**订单处理流程：**

1. **收到订单**：本地界面弹出订单通知，显示游戏名称、金额、客户信息
2. **抢单**（池子订单）：在订单池中看到感兴趣的单子，可通过 Agent 点击「抢单」
3. **确认接单**：点击「确认」按钮，订单状态变为 CONFIRMED（已确认）
4. **开始服务**：点击「开始服务」后填写游戏模式、单价、实际时长，并上传客户转账截图；以上信息必填，系统据此计算审核金额并计入服务证据链
5. **服务过程留痕**：服务过程中按系统设置的截图阈值（截图间隔/首张延迟/黑屏判定/每小时期望张数）自动截图，本地保存、结束服务时上传；文件名带实际时间戳，黑屏截图会额外标记
6. **完成订单**：服务完成后点击「完成」，订单状态变为 DONE（已完成）
7. **结束服务对账**：结束服务时填写「客户实际转账合计（微信 + 支付宝，元）」，留空记为待核对；低于「填写时长 × 单价」会被标记异常供管理端复核，高于则不追责
8. **证据长图**：系统自动把「服务信息表 → 转账截图 → 游戏截图 → 财务核对卡 → AI 异常分析卡」纵向拼接成一张长图，供管理端按时间线比对

**抢到单之后不用自己切菜单：** 在订单池点「抢单」、或在右下角急单弹窗点「同意」抢到单后，界面会直接跳到「订单管理」，并弹出一张成功卡片（里面有客户微信、房间码，可一键复制），关掉卡片就能看到刚抢到的单。在订单管理里点「✅ 添加成功」（或「客户已同意」）后，界面会直接跳到「客户管理」，找到该客户点「开始首单」就能开工。整条链路是：订单池抢单 → 订单管理 → 客户管理，不用再手动点左侧菜单。

**订单卡片上的内部编号：** 订单卡片右上角那个 🆔 小图标，鼠标悬停才会显示「客户ID：…」这种系统内部编号；日常看客户微信号和昵称就够了，不用记编号。

**每天能抢几单（每日名额制，2026-09-20 起）：** 每个陪玩每天按段位发「立即打」名额——
上等马 3 个、中等马 2 个、下等马 1 个。今天没抢完的**自动累计**到以后（今天剩 1 个，明天就是 3+1=4 个）。
预约单、客服指定给你的单、你自己发的单**不占名额**。订单池右上角会显示「今日名额（已用/每天）」，
名额用完点「抢单」会提示“今天的「立即打」名额用完了，可以抢预约单或等明天”。

**抢了不打单会被收回去：** 抢到单 180 分钟（3 小时）内没点「开始服务」、而且这单没有任何服务记录，
系统会自动把单退回订单池让给别人（**名额不退**）。所以抢单前确认自己这单能打；发布超过 24 小时的单
系统会直接作废并通知客服。

**新单弹窗打不打搅你，你自己定：** 弹窗只在你是「空闲」时弹（打单中/娱乐中默认不打扰，
弹窗秒数由老板在系统设置里配，线上 20 秒）。如果打单中也想第一时间看到新单，
在陪玩端首页把「打单/娱乐中也接收新单弹窗」开关打开即可。万一弹窗错过了也没关系：
急单会直接出现在订单池里，且广播单对你所在工作室是**立即出现**、不用再等 60/120 秒。

**群聊广播提醒：** 客服在工作室群聊里发广播时，你的电脑屏幕右下角会弹出一个红色提醒窗口（📢 + 客服名字 + 内容），置顶显示 5 秒后自动消失，不会抢你的键盘鼠标焦点，打游戏或最小化了客户端也能看到。看到广播后如果想接这单，回群聊回复客服即可；广播内容也会留在工作室群聊里，可以随时回头翻看。

### 6.4 报账提交

**时间口径（全系统只有这一种）：每天中午 12:00 换日。** 中午 12 点前打的单、报的账都算**前一天**的
（9/20 中午 12 点前报的账算 9/19；10/1 中午 12 点前报的账算 9/30）。

1. 进入报账页面，页面顶部选**营业日**（默认今天，可往前选）
2. 页面上列出这一天你已完成、且**还没报过**的场次（已报过的不会重复出现）
3. 勾选要报的场次、填写报账金额、上传**一张微信收款总截图**（微信一张就够，不用分别传）
4. 提交后报账进入「待审核」，等管理员审核

**漏报不用怕：** 昨天（或更早，最多 14 天内）忘了报，点报账页的「补报漏单」，
系统会把漏报的场次列出来让你补报——不再有「一过零点就报不了账、直接丢单」的问题。

**金额可以留空：** 结束服务时金额留空记为「待核对」，不影响报账；但**如果系统按真实计时算出来的金额
和你上报的差太多**，管理端会收到提醒，且你的报账单上会写清差额、相关场次会被标红（供管理端复核）。
这不是扣钱，是防止私单，老老实实填就没问题。

**能取多少钱（可支取余额）：** （当月累计业绩 × 你的分润比例）− 当月已支取 − 当月待审支取 − 未打存单预留。
其中**未打存单预留**= 你名下客户存单里**还没打完的余额，原样全额押着**（不打折）；只有**已经打完**的部分才按你的分润比例算进可支取。存单每打完一笔，预留就自动减少。
按月重置，存单没打完的部分会先替你扣住（防「冲完成绩跑路」）。

### 6.5 远程控制说明

管理员可通过「远程控制」页面对你的电脑执行以下操作：
- 关机/重启
- 网络限速/解除限速

当收到远程指令时，Agent 会自动执行。请确保在关键时刻保存好工作。

## 7. 核心工作流

### 7.1 订单全生命周期

```
客服创建订单
    │
    ├── 入池抢单 (POOL) ──▶ 订单进入订单池
    │                           │
    │                    ┌──────┴──────┐
    │                    │             │
    │              陪玩抢单 (grab)   客服指定 (assign)
    │                    │             │
    │                    └──────┬──────┘
    │                           │
    └── 指定派单 (DIRECT) ──────┘
                │
          状态: GRABBED
                │
          陪玩确认接单 (confirm)
                │
          状态: CONFIRMED
                │
          陪玩完成服务 (complete)
                │
          状态: DONE
                │
          陪玩提交报账
```

**状态转换规则：**

| 当前状态 | 可转换到 |
|----------|----------|
| PENDING（待处理） | GRABBED（已抢单）、CLAIMED（客服认领）、CANCELLED（已取消） |
| CLAIMED（客服认领） | PENDING（放回抢单池）、CANCELLED（已取消） |
| GRABBED（已抢单） | CONFIRMED（已确认）、CANCELLED（已取消） |
| CONFIRMED（已确认） | DONE（已完成）、CANCELLED（已取消） |
| DONE（已完成） | 不可转换（终态） |
| CANCELLED（已取消） | 不可转换（终态） |

**订单类型说明：**

| 类型 | 标识 | 说明 |
|------|------|------|
| 新单 | NEW | 新客户首次下单 |
| 续费 | RENEW | 老客户续费 |
| 复购 | REPURCHASE | 老客户再次购买 |
| 打赏 | TIP | 客户额外打赏 |

### 7.2 报账审核流程

```
陪玩完成订单 (DONE)
    │
陪玩提交报账 (含截图)
    │
报账状态: PENDING（待审核）
    │
    ├── 管理员审核通过 ──▶ APPROVED（已通过）
    │                          │
    │                    金额计入收入流水
    │
    └── 管理员拒绝 ──────▶ REJECTED（已拒绝）
                               │
                         陪玩可重新提交
```

**报账状态：**

| 状态 | 说明 |
|------|------|
| PENDING | 待审核 |
| APPROVED | 审核通过，已计入收入 |
| REJECTED | 审核拒绝 |

### 7.3 收入追踪流程

```
报账审核通过
    │
    └── 按日/按月汇总统计
            │
    ┌───────┴────────┐
    │                │
 日收入报表       月收入报表
 (按订单类型)     (按陪玩排名)
    │                │
    └───────┬────────┘
            │
    ┌───────┴────────┐
    │                │
  页面查看        CSV 导出
```

## 8. 常见问题 (FAQ)

### 账号与登录

**Q: 登录时提示"用户名或密码错误"怎么办？**

检查用户名和密码是否正确。如有疑问联系管理员重置密码。

**Q: 登录时提示"账号尚未通过审核，请联系管理员"？**

CS 和 COMPANION 角色的账号需要由老板审批后才能登录。请联系老板在「客户端授权」页面进行审批。

> 已办理离职的陪玩账号不能再次登录；系统会在登录、刷新登录态和后续接口校验时直接拦截，并提示“该账号已离职”。

**Q: 忘记二次密码怎么办？**

联系老板在后台重置二次密码。当前版本不支持自助找回。

**Q: 登录后能同时打开多个页面吗？**

可以。Token 存储在浏览器的 sessionStorage 中，同一浏览器新标签页需重新登录。

**Q: 登录后多久会自动退出？**

Access Token 有效期为 15 分钟，Refresh Token 有效期为 7 天。Token 过期后自动跳转登录页。

### 订单与派单

**Q: "入池"、"广播"和"指定"有什么区别？**

- **入池**：订单进入公共订单池，陪玩自己在池子里看到并抢单，先到先得，不会弹窗提醒
- **广播**：订单进池的同时，本工作室所有在线空闲陪玩的电脑右下角立刻弹出抢单窗口，适合需要马上有人接的单；如果这单同时向桥接工作室开放，桥接工作室的在线空闲陪玩会在「桥接工作室等待」时间到后收到同样的抢单弹窗
- **指定**：客服或管理员直接把订单发给指定的陪玩，只有他一个人会收到弹窗，其他陪玩看不到

**Q: 怎么看某个单是哪个工作室接的？**

订单管理列表里的「主陪 / 接单工作室」列就是这个用途：主陪名字下面就是他所属的工作室。本店陪玩接的显示灰色工作室名（如「蠢驴电竞」）；**桥接工作室的陪玩接的单会显示紫色「桥接·光耀电竞」**，一眼就能区分。悬停标签还会提示这单是谁发的、谁接的。

**Q: 客户端是不是一直在后台跑、很占资源？**

为了省电省流量，客户端做了这些收敛：连接用 WebSocket 长连接（不是每秒发请求），断线后逐步退避到最多 60 秒重试一次；前端版本检查 5 分钟一次、更新检查 30 分钟一次（紧急更新仍可用后台「推送更新」立即下发）；日志只保留最近 14 天并自动清理。

**Q: 发布后客户端多久会更新？**

在线客户端最迟 5 分钟内自动更新并重启；**正在接单的会跳过，等这单服务结束再更新**，不会打断计时和截图。

**Q: 陪玩可以自己发订单吗？**

可以。陪玩端（客户端里的网页界面）也能点「发布订单」自己建单——陪玩自己拉到的客户、或者临时补单，不用再回来找客服。

**Q: 订单可以取消吗？**

只有状态为 PENDING（待处理）或 GRABBED（已抢单）的订单可以取消。已确认或已完成的订单不可取消。

**Q: 为什么我看不到某些订单？**

不同角色看到的数据范围不同：
- 客服只能看到自己创建的订单
- 陪玩只能看到分配给自己或自己抢的订单
- 管理员可以看到本工作室所有订单

**Q: 池子里的订单为什么没有陪玩接？**

确认是否有空闲（IDLE 或 ONLINE 状态）的陪玩在线。陪玩需要在 Agent 客户端中切换到「工作模式」才能接单。

**Q：为什么我点了「抢单」抢不了？**
A：看订单池右上角的「今日名额」。每天的「立即打」名额按段位发（上等马 3 / 中等马 2 / 下等马 1），
没用完会累计；预约单、客服指定单、自己发的单不占名额。名额用完就去抢预约单，或者等明天。

**Q：为什么有时候不弹新单窗口？**
A：弹窗只在你「空闲」时推。打单中 / 娱乐中默认不打扰（很多人打游戏时最烦被打断），
想接新单的话去陪玩端首页打开「打单/娱乐中也接收新单弹窗」。另外新单都会进订单池，
错过弹窗不等于错过单子。

**Q：为什么客户端偶尔收不到弹窗、过一会儿又好了？**
A：以前登录令牌 15 分钟过期后，客户端拿着旧令牌重连会被服务端直接拒，那段时间一条弹窗都收不到。
现在系统会自动换新令牌再连（服务端也给了 7 天宽限），正常情况下不会再出现这种断续。

### 报账与收入

**Q: 报账审核被拒绝后可以重新提交吗？**

可以。被拒绝的报账可以修正后重新提交。

**Q: CSV 导出文件乱码怎么办？**

导出的 CSV 使用 UTF-8 编码并包含 BOM 头。在 Excel 中如果乱码，请使用「数据 → 从文本/CSV 导入」功能，选择 UTF-8 编码。

### 陪玩客户端 (Electron 客户端)

**Q: Electron 客户端 显示离线怎么办？**

1. 检查 Agent 程序是否正在运行
2. 确认网络连接正常，能访问后端服务器
3. 检查 `AGENT_TOKEN` 配置是否正确
4. 重启 Agent 程序

**Q: 切换娱乐模式后为什么还能收到订单？**

娱乐模式下状态为 IDLE（空闲），管理员仍可主动为你指派订单。如需完全拒绝新单，请退出 Agent。

**Q: 限速会影响游戏体验吗？**

限速 (500KB/s) 可能会影响在线游戏的网络表现。管理员通常在娱乐模式时使用限速，工作模式前会解除限速。

### 财务管理（对账 / 提成 / 分成 / 风险）

> 路径：左侧菜单 → **财务管理**

财务模块统一以「整数分」存储金额、以每日 12:00 为营业日边界，老板/店长/客服均可查看，写入（新增规则、运行结算）限老板/店长。

- **价格规则**：配置机密/绝密的首单底价与续单/复购区间；陪玩可在底价之上上浮报价。
- **提成结算**：配置客服/店长提成规则（按认领流水比例或按单固定），点击「计算当月提成」生成幂等月度结算。
- **月度分成**：按 5200/10000 阶梯 + 满 6 个月工龄门槛，运行并生成不可变结算快照。
- **到账对账**：按陪玩 × 营业日核对订单应收与员工收款码实际到账，差额标红。
- **支出/支取审核**：统一审核陪玩提交的支出/支取申请与钱包流水，支持月度汇总和通过/驳回。
- **提成复核**：提成结算列表可逐条「确认」或「撤销」草稿，锁定最终发放口径。
- **风险工作台**：AI 汇总单价偏低、时长腰斩、周消费突降、流失风险等信号并按私单风险评分排序，仅作抽查辅助、不自动判责。

### 系统与权限

**Q: 不同角色能看到对方的数据吗？**

系统按工作室和角色进行数据隔离：
- OWNER 可查看所有数据
- ADMIN 可查看本工作室的所有数据
- CS 只能看到自己创建的订单
- COMPANION 只能看到与自己相关的订单

**Q: 如何修改员工角色？**

联系老板在「员工管理」页面编辑员工信息。

**Q: 客户端最小化/缩到托盘后，界面还会自己刷新吗？**

不会。界面被切到后台（窗口最小化、被其它窗口完全挡住、切到别的应用）时，所有列表类的自动刷新都会停下来，
不再发请求；把窗口切回前台会自动继续按原来的节奏刷新。这样这些整天挂在托盘里的客户端不会白白占带宽和 CPU。
聊天消息走的是长连接，不受影响；订单池、人员列表这类「自动出现」的东西，切回前台时可能还是几秒前的样子，
点一下刷新或等一小会儿即可。

**Q: 客服 / 店长 / 老板 在人员列表里怎么算「在线」？**

看两个信号，取更新的那一个：① **客户端连接还在不在**——客户端开着，哪怕窗口最小化、收进托盘，
也算在线；② 客户端每 60 秒上报一次的心跳。两个信号都没有、超过 **5 分钟**，才显示离线
（陪玩是 2 分钟，因为陪玩端每 30 秒就报一次心跳）。真的把客户端退掉、或者电脑断网才会变离线。
窗口从最小化切回前台时会立刻补报一次，不用等满一分钟。

**Q: 可以添加更多工作室吗？**

可以。老板在「工作室管理」页面可创建多个工作室。

**Q: 陪玩端「动不动掉线 / 自己闪一下重新加载」是怎么回事？**

以前确实有这个问题：服务端每一次重启（我们每发一次版都会重启），陪玩端下一轮心跳就会把页面刷一次，
看起来就像掉线。现在修好了 —— 服务端重启不会再让任何客户端刷新；只有**真的发布了新前端**才会自动刷一次，
而且**正在接单 / 服务中的陪玩不会被刷**，要等这单结束、下一轮心跳才更新。
另外普通网络抖动导致的断开，服务端有 60 秒宽限期：60 秒内连回来就当作没掉过线，状态和弹窗都不受影响。
如果某个陪玩端还是反复掉线，先看两点：① 他客户端里存的是不是很旧的登录凭证（让他退出重新登录一次）；
② 他那边的网络 / 杀毒软件是否在拦 WebSocket，把客户端日志发我们查。
