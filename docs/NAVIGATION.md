# 导航与信息架构（2026-10-19 统一版）

> 目标：**一个外壳 + 四个角色工作区 + 统一标签**；角色能力层层叠加，名字相同、看到的范围不同。
> 这是入口/导航统一版；后续继续做工作台内容聚合与订单/客户/财务页签合并。

## 一级导航

| 角色 | 一级 |
|---|---|
| 老板 | 工作台、订单管理、客户管理、团队管理、工作室管理、财务、设置 |
| 店长 | 工作台、订单管理、客户管理、团队管理、工作室管理、财务、设置 |
| 客服 | 工作台、订单管理、客户管理、运营、财务、设置 |
| 陪玩 | 工作台、订单管理、客户管理、财务、设置 |

### 工作台

- **老板**：各工作室/俱乐部运营情况（流水、人员、订单、客户、待处理）、营收报表
- **店长**：本店运营看板（陪玩/客服状态墙、流水、人员、订单、客户、账号、待处理）、本店营收
- **客服**：本店运营看板（陪玩状态墙、人员、订单、账号、待处理）
- **陪玩**：我的流水 / 业绩、订单、客户、陪玩排名；**上传战绩图**放在等级评分旁边

### 团队管理（老板 / 店长）

- **陪玩**：陪玩列表、工作微信、实名审核、战绩图审核
- **客服**：客服列表、工作微信
- **店长**：店长列表（仅老板）
- **考勤与工资**：陪玩/客服/店长考勤管理、店长/客服工资规则

### 工作室管理（老板 / 店长）

工作室/俱乐部、工作室桥接、客户端授权（老板）、工作室账号、客户端与设备、内容查重。

### 财务

财务中心、陪玩审核+支取、应报 vs 实报、报账与支取日历、打私单风险、价格规则、客服今日看板 / 月度结算 / 微信收款明细。

### 客服「运营」

陪玩工作微信、客服工作微信、工作室账号、内容查重。

### 设置

系统配置、个人设置、高级设置（客服设置）。AI / 语音等是系统配置里的页签，不占一级菜单。
