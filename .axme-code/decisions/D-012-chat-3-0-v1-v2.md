# Chat 3.0 消息架构替代 V1/V2

Chat 3.0 使用 ChatRoom(双人房间) + ChatMessageV3(多类型消息 + 软删除撤回) + MessageReaction(emoji 反应) + ChatAuditLog(审计) 架构。支持跨工作室聊天(bridge)。旧版 ChatMessage(ChatMessageLegacy) 和 Conversation/ChatMessage(ChatMessageV2) 标记 @deprecated。

## Reasoning

Chat 1.0 (ChatMessageLegacy) 和 Chat V2 (Conversation + ChatMessage) 已被 Chat 3.0 替代。Chat 3.0 使用 participantA/participantB 字母序建房间，per-room 自增 seq 保证消息顺序，软删除(deletedAt)实现撤回，支持多消息类型和 emoji 反应。旧模型标记 @deprecated 待迁移后删除。
