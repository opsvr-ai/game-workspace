# 订单状态机严格转换

订单状态流转: PENDING → GRABBED(抢单) | CONFIRMED(派单) → DONE | CANCELLED。每次状态变更前调用 validateTransition() 验证合法性。已取消(CANCELLED)和已完成(DONE)为终态，不可再变更。

## Reasoning

订单有严格的生命周期：创建→抢单/派单→确认→完成/取消。每个状态转换必须验证前置条件，防止非法跳转（如跳过确认直接完成）。状态机确保了业务流程的完整性和可追溯性。
