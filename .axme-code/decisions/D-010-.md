# 四级角色权限体系

用户角色分4级: OWNER(老板) > ADMIN(管理员) > CS(客服) > COMPANION(陪玩)。使用 Nest.js RolesGuard 在路由级验证角色。OWNER 访问盈亏统计需额外通过二级密码(secondPassword)验证。

## Reasoning

系统有4种不同职责的用户角色。OWNER查看盈亏和全量数据，ADMIN管理陪玩和审核报账，CS处理订单和客户，COMPANION接单和服务。RolesGuard在路由级拦截，确保每个端点只有授权角色可访问。二级密码为敏感操作(盈亏查看)提供额外保护层。
