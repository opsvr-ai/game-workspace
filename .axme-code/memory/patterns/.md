# 跨工作室权限验证链

权限验证模式: 从 controller 的 @Req() req 提取 user.studioId → 通过 service 层传播 userStudioId → 在 workflow/业务逻辑入口添加 if (userStudioId && resource.studioId !== userStudioId) 守卫。此模式适用于 orders、companions、customers 等所有 studio-scoped 资源。
